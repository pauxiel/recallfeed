## Changes

1. **Opt-in CORS in the shared API** (`eada8b7`, `packages/api/src/middleware/cors.ts`).
   - Spec 09 puts the React app on Cloudflare Pages and the API on a Worker on another origin, which a
     browser blocks without CORS headers.
   - `CORS_ALLOWED_ORIGINS` (exact origins, or `*`) enables `Access-Control-Allow-Origin` for `GET` and `HEAD`
     on **public** deployments only.
   - It never sends credentials and never answers a preflight, so the API key cannot be used from a browser.
   - A private deployment never sends the headers, whatever the setting.
   - Unset means off, so existing deployments are unchanged.
2. **`apps/dev-recall`** (`bb937b7`).
   - A React 19 + Vite 8 + Tailwind 4 app. It reads the feed through `@recallfeed/client` with no API key,
     loads pages as you scroll (with a "Load more" fallback), and has an error state with Retry.
   - Note text is rendered through a pure parser (`src/content.ts`) into text, bold, inline code and code
     blocks. It never builds HTML.
   - `wrangler.toml` runs the shared `packages/api` with DevRecall's variables. `scripts/admin.ts` is the admin
     CLI (`import`, `review`, `list`). `scripts/seed.ts` imports and publishes 12 sample notes.
   - Differs from ReflectionFeed as the skeleton rules require: framework (Vite vs Next.js), visibility (public
     vs private), card types and strategy, theme, content, and its own Worker and database.

## Decision needed: a gap in Spec 09

A public deployment's `GET /feed` lists **published cards only**, even with the API key, and
`POST /import/markdown` returns **no card IDs**. So the admin CLI cannot publish a card it just imported, the
flow Spec 09 describes. I confirmed this against the running API. The seed script avoids it by publishing
through the database. Options for the shared API, each a small change:

- **(a)** return the new card IDs from the import;
- **(b)** let a key holder list unpublished cards (`GET /feed?include=unpublished`);
- **(c)** add a `publish` option to the import.

I recommend (b): it also lets an admin find a card to unpublish. I did not change the shared API without your
decision.
